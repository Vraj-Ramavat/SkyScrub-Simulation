# SkyScrub V0.3 Automatic Facade Standoff Validation

## Objective

Validate autonomous facade approach and standoff control using:

- Gazebo facade range sensing
- ROS 2 LaserScan
- PX4 ROS 2 DDS interface
- PX4 Offboard mode
- Closed-loop facade distance control

## Test configuration

- Desired facade standoff: 2.00 m
- Allowed deadband: +/- 0.08 m
- Maximum approach speed: 0.20 m/s
- Maximum retreat speed: 0.15 m/s
- Proportional range gain: 0.25
- Hover altitude: approximately 2.55 m
- Initial facade range: approximately 5.66-5.70 m

## Control flow

Facade
-> Gazebo front range sensor
-> ROS 2 LaserScan
-> SkyScrub standoff controller
-> PX4 TrajectorySetpoint
-> PX4 Offboard control
-> SkyScrub vehicle

PX4 successfully entered Offboard mode after receiving continuous

## Result

PASS

SkyScrub V0.3 successfully demonstrated closed-loop autonomous facade
approach and standoff control using simulated range sensing and PX4
Offboard control.

## Current limitations

- The 2.00 m standoff is a provisional simulation target.
- The front sensor is currently modeled as a narrow GPU lidar/range surrogate.
- Exact physical radar characteristics are not yet modeled.
- Wind and facade aerodynamic effects are not yet included.
- The controller currently holds one fixed approach direction.
- Facade lateral and vertical scanning are not yet implemented.
